# 🛡️👁️ مانع لقطات الشاشة · Screenshot Blocker

تطبيق أندرويد مفتوح المصدر يمنع لقطات الشاشة وتسجيلها، في كل التطبيقات أو في تطبيقات تختارها.

- بلا إنترنت · بلا تتبع · بلا إعلانات · بلا سجل أو تاريخ
- لا يخزّن إلا إعداداته (مفعّل/متوقف + قائمة التطبيقات المختارة)
- واجهة مظلمة، وخدمة أمامية خفيفة (فحص واحد كل ثانية)

## كيف يعمل؟
تعرض الخدمة طبقة شفافة غير قابلة للّمس بعلامة `FLAG_SECURE` فوق الشاشة، فيعرضها النظام سوداء في اللقطات. في وضع "تطبيقات مختارة" تظهر الطبقة فقط حين يكون أحدها في المقدمة (عبر `UsageStatsManager`).

## الصلاحيات
| الصلاحية | السبب |
|---|---|
| `SYSTEM_ALERT_WINDOW` | عرض الطبقة الآمنة |
| `PACKAGE_USAGE_STATS` | معرفة التطبيق الحالي (وضع الاختيار فقط) |
| `FOREGROUND_SERVICE(_SPECIAL_USE)` + `POST_NOTIFICATIONS` | الاستمرار بالخلفية بثبات |

## حدود معروفة
- لا يمنع تصوير الشاشة بكاميرا أخرى.
- بعض الشركات المصنّعة تتعامل مع الطبقات الآمنة بشكل مختلف؛ جرّب على جهازك.
- مستخدمو الروت/ADB قد يتجاوزونه.
- قد تحتاج بعض الأجهزة استثناء التطبيق من توفير البطارية.

## البناء
```bash
gradle wrapper --gradle-version 8.7   # مرة واحدة
./gradlew assembleDebug
```
أو ادفع إلى GitHub وسيبني الـCI ملف APK (وسم `v1.0.0` ينشئه في Releases).
